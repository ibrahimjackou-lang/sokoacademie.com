# SOKO Académie Football - Template Web HTML/CSS

Ce dossier contient le modèle de site web complet (HTML5, CSS3, JavaScript) reproduisant fidèlement la maquette de **SOKO Académie Football** (Niamey, Niger).

## Structure du dossier :
```text
soko_template/
│
├── index.html         # Page principale du site web
├── css/
│   └── style.css      # Feuille de style complète et responsive
├── js/
│   └── main.js        # Script JavaScript pour les interactions et défilement fluide
└── images/            # Dossier réservé pour vos images (logo, bannières, etc.)
```

## Utilisation :
1. Décompressez l'archive ZIP.
2. Ouvrez le fichier `index.html` dans votre navigateur web ou éditeur de code favori (VS Code, etc.).
3. Personnalisez les textes et ajoutez vos images dans le dossier `images/`.
